# Lecciones aprendidas

<!-- Errores, descubrimientos y trucos que el agente debe recordar. -->

- Un láser siempre encendido no puede cumplir las reglas de apagado por pérdida, parada o timeout. La seguridad debe trasladarse al corte físico, al operador y a un blanco seguro; además hay que registrar el riesgo residual de exposición ocular.
- Un botón mantenido con cinta no es un corte de emergencia fiable. Si se usa, debe quedar documentado y se recomienda un interruptor de retención o una seta.
