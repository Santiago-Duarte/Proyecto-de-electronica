# Glosario

<!-- Termino: definicion. Vocabulario del dominio. -->

- **Corte físico:** botón o interruptor que corta la alimentación del módulo láser. Es el único medio admitido para apagar el láser; no depende de firmware, web ni PC (ADR-011).
- **Láser siempre encendido:** el módulo láser se alimenta por batería y permanece encendido mientras el botón mantenido esté presionado. El software no lo enciende ni lo apaga, y sigue encendido en pérdida, parada, tope, error de enlace, reinicio o caída del proceso.
- **Apuntado:** dirección del eje óptico del láser sobre el torso del objetivo. Se considera centrado cuando el punto de apuntado cae en la zona central del encuadre.
- **Objetivo confirmado:** detección del objetivo que se mantiene durante un mínimo de frames consecutivos configurable.
- **Ventana de gracia:** concepto eliminado por ADR-011. Ya no existe margen entre la pérdida del objetivo y un apagado del láser.
