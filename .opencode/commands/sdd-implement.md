Implement spec: $ARGUMENTS

1. Read spec.md, plan.md, tasks.md, docs/constitution.md and docs/memory/*.md.
2. Work on unchecked tasks in order, one at a time. Run the project tests after each one.
3. Check off each finished task in tasks.md.
4. Record notable decisions in docs/memory/decisions.md and surprises in docs/memory/lessons.md.
5. If the code needs to diverge from spec or plan, stop and ask me before continuing.
